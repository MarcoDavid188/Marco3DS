El siguiente proyecto se refiere al desarrollo de un Sistema de Inventario y Ventas. Este sistema contará con los módulos de compras y ventas, lo que permitirá llevar un control adecuado del inventario.

A través de la gestión de inventarios, se podrán registrar las entradas de productos (compras) y las salidas de productos (ventas). Además, el sistema permitirá generar reportes de inventario basados en el stock disponible, facilitando así la administración y control de los productos.

Sistema desarrollado por el aula 3DS.
